# RC Track Designer v0.4.0 Beta 1

## Deutsch

Diese öffentliche Beta ergänzt den bisherigen Streckeneditor um einen
Hallenmodus für temporäre Indoor-RC-Strecken. Auf einer anthrazitfarbenen
Teppichfläche lassen sich maßstabsgetreue gelbe Begrenzungsgeraden und
Kurvensegmente frei platzieren, drehen, verlängern und magnetisch verbinden.

Weitere Neuerungen:

- Begrenzungsbreiten von 5, 10, 15, 20 und 25 cm
- unabhängige Begrenzungsketten und freistehende Elemente
- zusätzliche verschiebbare Magnetpunkte auf geraden Begrenzungen
- Undo/Redo, Mehrfachauswahl sowie JSON-Speicherung im Hallenmodus
- rückwärtskompatibles Laden der Projektformate 1 bis 3
- sicherer Moduswechsel mit vorherigem Speichern und leerem Zielbereich

Beta-Hinweise: Der Build ist nicht digital signiert. Windows SmartScreen kann
daher eine Warnung anzeigen. Bitte Projekte regelmäßig speichern und Fehler
möglichst zusammen mit der betroffenen `.rct.json`-Datei melden.

## English

This public beta adds an indoor mode for temporary indoor RC tracks while
retaining the established track editor. Scale-accurate solid yellow straight
and curved barriers can be placed, rotated, resized, and magnetically connected
on an anthracite carpet area.

Further additions:

- barrier widths of 5, 10, 15, 20, and 25 cm
- independent barrier chains and freestanding elements
- additional movable magnet points on straight barriers
- Undo/Redo, multi-selection, and JSON persistence in indoor mode
- backward-compatible loading of project formats 1 through 3
- safe mode switching with mandatory saving and an empty target area

Beta notes: The build is not digitally signed, so Windows SmartScreen may show
a warning. Save projects regularly and, when reporting an issue, include the
affected `.rct.json` file whenever possible.
