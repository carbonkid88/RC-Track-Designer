# RC Track Designer v0.4.0 Beta 2

## Deutsch

Beta 2 erweitert insbesondere den Hallenmodus um eine besonders flexible Bearbeitung von Streckenbegrenzungen.

- Alle Begrenzungsanschlüsse unterstützen mehrere Geraden und Kurven an einem gemeinsamen Knoten.
- Verbundene Endpunkte lassen sich wie Gelenke direkt verschieben.
- Geraden passen dabei Länge und Winkel an; Kurven passen ihren Mittellinienradius an.
- Gegenüberliegende Anschlüsse und der übrige Streckenverlauf bleiben an ihrer Position.
- Verbindungen an verschiebbaren Zusatz-Magnetpunkten bleiben als Gelenkketten erhalten.
- Reguläre Berührungen an Mehrfachknoten erzeugen keine falsche Überlappungswarnung mehr.
- Projektformat 5 speichert Mehrfachverbindungen; Formate 1 bis 4 bleiben ladbar.
- Neues Anwendungssymbol, übersichtlicher Fenstertitel und Projektname in der Streckenbereichsanzeige.
- Das Menü „Ansicht“ heißt jetzt „Einstellungen“.

Dies ist eine öffentliche Betaversion. Rückmeldungen und Fehlerberichte sind über GitHub Issues willkommen.

## English

Beta 2 focuses on a much more flexible indoor-mode barrier workflow.

- Every barrier connector supports multiple straights and curves at one shared junction.
- Connected endpoints can be dragged directly like joints.
- Straights adjust length and angle; curves adjust their centreline radius.
- Opposite connectors and the remaining layout stay in place.
- Connections at movable additional magnet points remain joined as articulated chains.
- Intentional contact at multi-way junctions no longer causes false overlap warnings.
- Project format 5 stores multi-connections; formats 1 through 4 remain loadable.
- New application icon, concise window title and project name in the track-area caption.
- The “View” menu is now named “Settings”.

This is a public beta. Feedback and bug reports through GitHub Issues are welcome.
