# Anwendungsscreenshots / Application screenshots

In diesem Ordner werden ausschließlich echte Screenshots von RC Track Designer
abgelegt. Für den dreispaltigen Screenshot-Bereich der Haupt-README sind diese
Dateinamen vorbereitet:

| Datei | Inhalt |
|---|---|
| `application-overview.png` | Programmübersicht / Application overview |
| `classic-track-mode.png` | Streckenmodus mit fertigem Layout / Track Mode with a finished layout |
| `indoor-mode.png` | Hallenmodus mit Begrenzungslayout / Carpet Mode with a barrier layout |

Empfehlungen:

- PNG-Format mit gut lesbarer Benutzeroberfläche verwenden.
- Für alle drei Bilder möglichst dasselbe Seitenverhältnis wählen.
- Persönliche Daten und lokale Dateipfade vor der Aufnahme ausblenden.
- Keine künstlich erzeugten oder nachgebauten Oberflächen verwenden.

Die Haupt-README bindet diese drei echten Anwendungsscreenshots direkt ein.
